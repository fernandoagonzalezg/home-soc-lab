# Home SOC Lab

A hands-on Security Operations Center (SOC) laboratory designed to
develop practical skills in security monitoring, SIEM, endpoint
detection, network monitoring, incident response, threat intelligence,
and detection engineering.

## Objectives

- Build and operate a small SOC environment
- Collect and analyze endpoint telemetry
- Deploy and configure a SIEM
- Monitor Windows and Linux systems
- Develop security detections
- Investigate simulated security incidents
- Perform network security monitoring
- Document incident response procedures
- Develop security automation
- Apply NIST-aligned security practices

## Lab Architecture

The lab consists of:

- Windows endpoint
- Linux endpoint
- SIEM
- Raspberry Pi network/security sensor
- Virtualized lab network
- Attack/test environment

## Technologies

- Wazuh
- Sysmon

- Linux logging
- Wireshark
